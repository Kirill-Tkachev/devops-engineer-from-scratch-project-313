# Проект "Деплой приложения на PaaS"

## Требования
- Python 3.12 или выше
- uv
- GNU Make


## Установка зависимостей
uv sync


## Запуск приложения
make run


После запуска приложение будет доступно по адресу:
http://localhost:8080/ping


При успешном запуске маршрут `/ping` возвращает ответ:
"pong"
